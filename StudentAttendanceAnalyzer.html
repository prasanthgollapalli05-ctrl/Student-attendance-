Project Information

Project Title: Student Attendance File Analyzer

Problem Statement: Collect student attendance details, calculate attendance percentage, store the complete information, and identify students whose attendance is below 75%.

Formula: Attendance Percentage = (Classes Attended / Total Classes) × 100

Concepts Used

  • Variables and data types
  • User input and validation
  • Arithmetic operations
  • Conditional statements
  • Arrays and objects
  • File-style data handling
  • Exception/error handling
  • Basic problem solving

Constraints

  • Total classes must be greater than 0.
  • Classes attended cannot be greater than total classes.
  • Attendance percentage is calculated accurately.
  • Invalid input is handled without terminating the page.
  • No database or external library is used.
